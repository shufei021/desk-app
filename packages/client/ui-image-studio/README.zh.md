# @deepseek-ai/dsh-client-ui-image-studio

[English](README.md) | 中文

## 概述

使用你在**设置 → 模型 → 会话生图**中配置的生图服务生成图片，不经过聊天模型、工具调用或 Agent 回合。工作区展示最近生成的图片，可重新打开历史结果并下载，并各自保留参数选择、预设、参考图、蒙版、资产库、变体对比与提示词助手。它与 [直接交互页面](../ui-direct-ai/README.zh.md)共用 Direct AI Remote 与请求历史，但本身是独立的浏览器插件：图像面板、侧栏入口与会话模式栏都由本包注册。提供商密钥只写入 Host 凭据存储。

<a id="use-this-package"></a>
## 使用本包

在侧栏打开**图像生成**。页面只列出已配置且能力为生图的服务，提交后直接调用生图接口，不经过聊天模型、工具调用或 Agent 回合，因此不需要聊天模型支持工具调用。工作区展示最近生成的图片，可重新打开历史结果并下载。每张结果卡片在图片旁显示产生它的提示词，以及服务、模型、时间、参考图数量和预设，并可复制或再次使用该提示词；提示词由 Host 随请求留存，刷新后仍在，预设模板文本不进入其中。最近生成以提示词首行作为标题。生成结果可沿白色网格线拆分为可直接下载的子图。一次请求最多可添加 8 张参考图，图片作为附件保存，并按参考图编辑发送。会话输入框上方的**工作模式**在对话与图像生成之间切换；切换只改变当前工作区，不修改已有会话历史。没有可用生图服务时，先在**设置 → 模型 → 会话生图**添加服务并保存密钥。

图像输入框是描述框加一行工具栏。左侧的 **+** 添加最多 8 张参考图（缩略图显示在描述框上方，已加蒙版的缩略图带标记），其后是**生成模式**菜单、**资产库**、**提示词助手**、**参数**与**变体对比**；右侧是字符计数（`n/4000`）、服务菜单与发送或停止按钮。运行中发送按钮变为**停止本地请求**。

**生成模式**菜单在自由生成与两个固定模板之间切换：**角色三视图**生成工作室肖像与正交的正面、侧面、背面全身视图，**场景多视角**生成不同相机角度的 2×2 网格。两个模板都要求恰好 1 张参考图，并在你的描述之后附加固定指令，因此描述可以留空；输入框仍只显示你填写的文字。切换模式不会清空描述与参考图。预设模板是提交给模型的提示词，不是本地化 UI 文案。

**参数**弹层设置画面比例（10 种固定比例或跟随首张参考图的**原图**）、分辨率（长边 1K/2K/3K/4K）、质量（低/中/高）、生成数量（1–4）和具体宽高。尺寸超出范围时就地收敛而不是提交失败：宽高均为 16 的倍数，总像素不超过 8,294,400，长宽比不超过 3:1；打开锁定比例后，输入一边会按比例推导另一边。选中的尺寸、质量与数量作为明确的 `size`、`quality`、`n` 参数提交，本浏览器记住上次选择，结果卡片会显示这三项。从未打开参数弹层的输入框不发送这些参数，交由服务商决定。

**提示词助手**按钮位于**资产库**与**参数**之间。它通过已配置的对话服务把当前描述扩写成一段提示词，并在工具行上方以内联面板流式显示；固定指令要求输出一段可直接用于文生图的中文提示词，覆盖主体、构图、光线、材质、风格和画质，且不超过 600 字。**扩写**发送当前描述，**停止扩写**结束本地等待，**采用**把结果写回描述框但不提交、不改参数，**重新生成**用同一描述再请求一次。本浏览器记住所选对话服务。没有已配置的对话服务时按钮禁用，并指向配置提示。每次扩写都是普通的对话请求，会保留在直接交互的请求历史中，不会触发生图。

**变体对比**把同一段描述分别按多种风格生成并横向对比。选择 2、3 或 4 个变体，勾选要参与的风格（摄影写实、电影感、插画、3D 渲染、水彩），再点**开始生成**。勾选的风格逐个串行执行、绝不并发，因此服务商的并发上限和花费都可预期；面板显示当前是第几列，保留每个已完成的列，某个风格失败时显示它的错误码，其余风格继续。**停止批次**会中断正在运行的流和之后的所有风格，已完成的列保留。每列提供**打开或下载**与**用这张**：后者把描述与该风格的风格提示一起写回描述框并关闭面板，不会提交。每列都使用输入框当前的参数，历史记录里保留产生该图的那段带风格的提示词。风格后缀是提交给模型的提示词，不是本地化 UI 文案。

当描述暗示的选择与当前参数不同时，工具行上方会出现建议条，显示建议的比例、分辨率、质量、数量和理由。选择顺序为：先看所选生成预设，再看构图词（竖、人像、风景、全景、方图），接着是质量词（4K、印刷、高清细节，对比草图、快速、缩略）和数量词（多个方案、对比备选）；已添加参考图时，4K 目标会降到 2K，因为参考图长边通常不超过 2K。**应用**把建议写入输入框参数并记住，**忽略**只隐藏本条，直到描述变化。两者都不会提交请求；与当前参数相同的建议不会显示。

恰好 1 张参考图且生成模式为**蒙版编辑**时，**编辑蒙版**会在该图上打开画笔；擦出的区域变为透明，蒙版 PNG 作为附件保存并随请求提交，服务商只编辑这些区域。

**资产库**把参考图保存在已注册工作区的资产文件夹里。面板列出已注册的工作区，并优先打开你在本浏览器上次选择的那一个，没有记录时使用第一个。图片按分类存到该工作区的 `资产库/角色`、`资产库/场景` 或 `资产库/道具` 下；文件名即标题，重名会自动加序号。把已保存的资产用作参考图时，Client 从 Host 取回图片、转回文件，再走与手动选择文件相同的上传路径，因此同样受 8 张上限约束。每个资产显示分类和修改时间，删除需要再次点击确认。文件保存在工作区磁盘上，可直接在资源管理器查看，浏览器数据被清除也不受影响，不同工作区各自保留一份资产库。

Web 组合将本浏览器插件与 Direct AI Host 提供方及直接交互页面一起挂载。它注册图像面板、侧栏入口和会话输入框模式栏；直接交互页面注册自己的面板与服务编辑。仍然要求 owner 身份认证，提供商配置独立于用于配置 Agent 的**设置 → 模型**。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现细节 — 点击展开</summary>

本插件通过 Slots 提供一个 root 作用域主页面、一个侧栏入口和一个 `conversation.input.dock` 模式栏。它从共享的 `@deepseek-ai/dsh-client-direct-ai-client` 包创建自己的 `DirectController` 实例，消费 API Remotes 挂载的生成 `directAi` namespace，因此图像工作区与直接交互页面不共享运行时请求状态。资产面板读取 `workspaceAssets` namespace，并通过需要鉴权的 Host 字节路由显示已保存的图片。UI 文案由 `imageStudio` namespace 的语言字典拥有，页面偏好不存储任何凭据。插件释放时等待活动请求结束，再撤回界面。

</details>

<a id="model-experience"></a>
## 模型体验

### 直接图像请求

#### 模型看到的内容

图像工作区不提供 Agent 工具、角色、工作区指令、技能或自动系统提示词。所选生图服务通过 Host 提供方接收用户描述、参考图、蒙版与明确参数；提示词助手的固定指令只发送给用户选择的对话服务。

#### Token 影响

只有描述、所选预设模板或风格后缀、固定的助手指令与明确的 `size`、`quality`、`n` 参数进入提供商请求。工作区不添加你未选择的指令，使用量和费用由提供商决定。

#### KV Cache 影响

只有用户提供的提示词、预设模板与提供商参数影响图像请求的前缀。对话历史、Agent 会话与工作区指令都不参与。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- 此版本只接受文本和参考图输入；上传视频输入和音频生成需要单独适配器。
- 能力配置是声明，不是连接或权限测试。无效密钥也可能保存，请求时会显示服务商拒绝。
- 页面草稿、记住的服务与记住的参数保存在浏览器内存。Host 保留的请求历史跨刷新存在，但活动流不会重连或重新提交。
- 没有独立字典的 UI 语言回退到英文。
